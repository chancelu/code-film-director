# 风格库（传统文化 · 哲学 · 科普）

从 lemo-opuscar 51 种风格里挑出与三类内容契合的 12 种，按 STYLE.md 的固定结构压缩成配方。每种：本质（是/不是）、材质与渲染、配色逻辑、字体字幕、运动、镜头词汇、声音、原生招式、坑。

多数"国风"引擎只做到"金色粒子 + 2.5D 视差"，缺水墨的核心：**笔触生成、留白、五墨分色、墨晕转场、只一抹朱砂**。通用升级路线见文末。

## ① 水墨写意 Ink Wash（传统文化首选）
- **本质**：宣纸上实时画出来的写意水墨，空白纸就是空间，一笔就是山、浪、一个动作或一次切换。不是水彩（无彩色晕染），不是加了笔刷纹理的矢量（无平涂、无闭合描边），不是书法片头。
- **材质**：程序化宣纸（约 `#F2ECDE`，云状斑驳、长纤维、纸浆点、拉远时纹理减弱、暗角），固定在世界坐标。墨 = 笔画不透明度正片叠底到纸上，**五墨**：焦 .96（书法、最锐线、苔点）/ 浓 .82（轮廓）/ 重 .60（次线、衣褶）/ 淡 .34（山体、衣身）/ 清 .16（远山、雾、人脸）。笔画 = 中心线 × 压力曲线 × 宽度噪声 + 4–60 根"笔毛"，墨量沿笔画递减、在长尺度噪声处断开 → 飞白。湿层在合成器里洇开（噪声模糊 + 边缘积墨），干层只加纤维抖动。山向下化入雾带；水就是空白纸。书法字体只当骨架：按笔顺描中心线、藏锋入笔、收笔渐细。
- **配色**：只有墨（低浓度偏冷灰、高浓度偏暖黑）+ **一抹朱砂**（约 `#B02E22`）给印章和故事里至多一个小物。不铺红、不用红字。画面乱了就减墨，不加色调。
- **字幕**：题跋式——墨色衬线斜体（中文用楷/宋 OFL 字体），无底框，≤2 行，放在每个镜头的留白处，行首一个小朱砂方块；落笔即干。标题竖排写在画里，配代码画的白文印。
- **运动**：人物 12 fps 一拍二，相机/墨晕/涟漪 24 fps；笔画按书写顺序出现；决定性一笔前"静止→一笔划过画面→再有后果"。不做矢量式补间：东西是画出来、洇开、化入雾的。
- **镜头词汇**：固定画面（东西被画出来）；右→左横摇（手卷，时间即距离）；竖向移（立轴，层层叠加）；高远小人（渺小）；低角黑压压推进（压力）；硬切大特写（全风格唯一的硬切）；推入墨晕/雾（状态转换）；拉远直到一笔融入整体（总结）。画面 60–80% 留白。转场只用墨晕、沿卷轴摇、雾；不用通用溶解或划像。
- **声音**：古琴主导（散音、按音、滑音、泛音），低沉的箫，大鼓定量感，小锣配印章，五声调式。随画面写，不循环。静音是真静音，里面最多一滴水。拟音：墨滴（短"叮"+湿闷声）、笔刷（带通噪声+毛刷颗粒，不要金属呼啸）、印章（木闷声+纸响）。
- **原生招式**：一笔即万物；留白即实体（去墨露出纸白＝开门、人群分开）；笔顺即编舞；**飞白**（静默后一笔干笔横穿画面）；**墨晕转场**（下一场在扩散的墨滴里长出来，带深色潮线）；手卷（一幅长画右→左摇完再见全貌）；劈开（一块墨团被一刀两分）。
- **坑**：干笔像虚线 → 用长尺度噪声断墨；平行半透明笔画像管风琴 → 一块底色 + 两道饱墨笔；大侧锋像梳子 → 渐变块 + 少量低干度笔。
- **用法示例**：太极生两仪＝一个墨点洇开分阴阳；八卦＝三笔一卦按笔顺写；四季更替＝手卷横摇；诗句＝按笔顺写出再落印；钩子回收＝飞白。

## ② 皮影 Shadow Puppetry
- **本质**：白布幕后，半透明染色兽皮偶被油灯从后打亮；颜色靠透射光，镂空最亮，重叠变暗；关节有线铆钉，细杆可见；幕随灯闪、偶在手里抖、零件绕铆钉摆。不是黑剪影，不是剪纸（光是透过来的），不是彩窗（无铅条）。
- **配色**：全部透射、偏暖，没有比灯更亮的；3–5 种饱和染料 + 生皮色 + 墨；夜晚 = 灯少，不加蓝。细的东西（线、文字）用深色。
- **声音**：锣鼓经打击乐优先（堂鼓、梆子、钹、小锣"台"上扬、大锣"匡"下沉），板胡/二胡式鼻音弓弦，竹笛做安静段。
- **原生招式**：光就是世界（灯数＝热度/时间）；离幕＝变大变糊（谣言变大、记忆淡去）；**绕到幕后**（揭示原理：谁在操控）；镂空透光（系统的 X 光、善恶对照）；手持颤抖。
- **适合**：讲故事型（女娲、伏羲画卦、河图洛书传说）、"幕后的规律"类哲学题。

## ③ 纸雕灯影 Paper-cut Lightbox
- **本质**：每个镜头是一个浅盒子里的平行剪纸层：每层一个平涂色 + 顶边暖光边 + 底边暗带；后层亮而冷、前层近黑——明度阶梯就是景深。光透过纸有云状纸浆感；顶灯给每层投软影到后层（永远不关）。
- **配色**：后亮前暗不可破；每摞一种色温，换色温＝换地方；光是暖金，是除一个强调色外唯一饱和的东西。
- **声音**：毛毡钢琴、八音盒、钢片琴、竖琴/古筝、竹笛；无鼓组。拟音：开关咔嗒 + 上扬微光声、纸摩擦、卡纸轻敲。
- **原生招式**：灯亮了（光源→远层→窗一扇扇亮）；两扇窗共一个月亮；深度即距离；纸自己写字；盒子是信物（镜头最后找到桌上的真灯）。
- **适合**：节气、月令、"时辰是一座钟"、中秋/春节节点集。

## ④ 红色窗花剪纸 Papercut Red
- **本质**：一切都是剪刀剪出来、平贴在另一张纸上；无绘画、无渐变、无描边，细节只来自剪掉的部分；关节剪纸偶 12 fps 硬步进。正面光、不透明；背光是留给关键时刻的特效。
- **配色**：中国红（`#d2201f` 左右）是主角材质；深度靠一阶之差的纸色；**底和主体必须不同纸系**（红底红偶会糊成一团）。
- **声音**：剪刀金属剪切扫频 + 纤维裂声、折纸、展开"啪"、硬纸板脚步；琵琶轮指、古筝分解和弦的明亮丝竹。
- **原生招式**：**折—剪—展**（一剪成多，展开落在强拍）；镂空即光；对称复制（团花→窗花→烟花）；碎屑有未来（剪下的碎纸变雪/星）。
- **适合**：生肖、年俗、"一生二二生三"的复制繁衍、春节特辑。

## ⑤ 木刻版画 Woodcut
- **本质**：每个镜头是一块印版：黑是木头，白是刀刻掉的；画面靠"被刻出来"出现（粗刀先、细线后，不淡入）；版是镜像，揭纸那一下字才变正。
- **配色**：近黑墨 + 暖纸白；最多一块色版，只印在刻白处（火、心、信号灯）。
- **声音**：低音弦拨奏、木鱼/梆子、框鼓、定音鼓、一面大锣；刀刻拟音。
- **原生招式**：光是刻出来的（放射刀痕＝顿悟）；刻＝时间；**镜像版→正印**（误解被纠正、真名显现）；唯一色版扩散又收回。
- **适合**：哲学（顿悟、知行、"刻意练习"）、"误解→正解"型选题。

## ⑥ 一笔画 One-line（哲学首选）
- **本质**：暖白纸上一根不离纸的线，整片可以真的就是一个点数组；一切都是线，无填充、无第二种线宽；我们看着线被画出，镜头略带滞后地跟着笔尖。最多一个强调色、只用一次。
- **声音**：一件独奏乐器、一条不断的旋律线（大提琴、单簧管、古琴、哼唱）；关键笔触落关键音；笔停＝一个长音渐入静默。
- **原生招式**：笔不离纸（连续性、因果链）；线即时间（线的质感随年龄/情绪变化）；变形（种子→树→桌子；概念→其反面）；**停笔是事件**（墨聚、静音 1.5–3 s）；逆向设计的尺度揭示（每个小场景其实都是一幅大画的一部分）。
- **坑**：多余连线会读成皱纹/胡子 → 像欧拉路径一样规划每章出入口；尽早整体渲染检查揭示图。
- **适合**："万物一体""缘起""庄周梦蝶""忒修斯之船"、人生/时间主题。

## ⑦ 铜版画 Copperplate Engraving
- **本质**：凹版：调子全由线组成（亮＝纸，半调＝一组平行线，阴影＝交叉第二组，最暗＝第三组菱形网）；每根线入刀细、中段深、出刀尖；颜色最后手工水彩平涂、溢出线外、边缘积色，墨永远在上。
- **原生招式**：刻刀一线；三遍成形；**放大圆框**（圈出细节飞到页边加标注——科普解剖神器）；揭纸印出；版的修订状态（前后对比）；手工上色（一个器官被点亮）。
- **适合**：博物科普（植物、昆虫、天文仪器、浑天仪）、哲学史人物。

## ⑧ 1920s 默片 Silent Film
- **本质**：单色银盐，按段落染色（出事更冷更破损，温情更暖更干净）；明度承担一切；最多一个分色元素保留色相。字幕卡式文字。
- **声音**：一台立式钢琴即全部音效（半音爬行＝偷偷摸摸、倚音＝眨眼、前臂音簇＝撞击、渐强减七震音＝等待、下滑音＝跌倒）。
- **坑**：内容太多会毁掉默片——一条清晰的因果链中间带停顿，胜过三条忙乱的。
- **适合**：哲学思想实验（电车难题、囚徒困境）、科学史小故事。

## ⑨ 白板讲解 Whiteboard（科普首选之一）
- **本质**：一块真白板；观众学到的一切都按真实书写顺序用白板笔画出；**白板是地图**：每个观点占一块区域，镜头在区域间移动，板上距离＝论证距离；墨在笔尖落点积聚、有干痕、笔画略冲出不完全闭合、旧课残影、反光比板慢；**每一笔都有声音**；不画手。
- **配色**：最多三色且全片含义固定：深色＝事物与结构、蓝＝信号/测量/过程、强调色＝要紧的那一个（每区一个）。
- **声音**：毡头在光面上的带通噪声按笔速包络 + 起笔小"嗒" + 偶尔干擦吱声；磁铁咔嗒、板擦摩擦。
- **原生招式**：**按讲解顺序逐项写公式**；笔带镜头（转场是镜头骑着一条画出的线）；磁铁（唯一能动的东西：主角给磁铁）；**板擦倒带**（"如果没有……"）；双笔对写。
- **结构**：证明（顶部一个命题，逐步向下推导，每步证毕框起）；辩论（两支笔两半板，最后在中间相遇）；时间轴（一条长横线左→右）。
- **适合**：推导与换算（公式、历法、卦象）、逻辑与因果类科普。

## ⑩ 瑞士动态排版 Swiss Motion
- **本质**：网格上的纯 2D 平面设计：平纸、黑字黑条、极浅灰 + **一个**饱和信号色；一切吸附网格、每次移动落拍、不弹跳；全帧服从一个系统，所以唯一不服从的元素成了角色；极端尺度对比（巨型数字旁是小注释）。
- **原生招式**：网格有含义（列＝时辰、行＝年份）；吸附＝节拍；程序（规则一条条施加到一件作品上）；极端尺度对比做章节卡；**例外**（一个元素打破网格）。
- **适合**：列举/清单型（节气表、元素周期表、排行榜）、哲学"规则与例外"。

## ⑪ 数据叙事 Dataviz（科普首选之一）
- **本质**：图表就是影片。每个标记是真实数字，每个运动是有意义的图表操作（落点、坐标轴生长、换尺度、序列变形、钉注释）。数据真实可溯源，只改构图不改数字。按数据选图：排名→条形赛跑；两量关系→散点；地点→地图；部分与整体→单位/华夫图；前后→斜率图；分布→直方/蜂群；流向→桑基。
- **配色**：颜色只编码"值"；发散数据用以参考期均值为中心的对称色带；**诚实胜于戏剧**，不拉伸色带夸大变化。
- **声音**：可听化即配乐（音高＝值、节奏＝时间密度）；铅笔、纸、尺的拟音。
- **原生招式**：一个标记＝一个事实；坐标轴在旁白第一次说出单位时才长出；钉注释；**冲破画框**（峰值撕开边框留疤）；编码变形（条形→华夫，揭示整体）。
- **坑**：按列名取数，打印旁白引用的每个数字；破框状态至少停半拍。
- **适合**：节气与实测气温、日影长度、月相周期、人口/气候/经济等任何有真实数据的题目。

## ⑫ 档案灯台 Archive Lighttable
- **本质**：物件是真的（公有领域扫描件，真实比例、真实破损）；灯从下面来；**放大镜是镜头的门**：每次深入都通过一个落在物件上的放大镜；画面上的编号、日期、数字都来自馆藏记录；一个信号色。
- **原生招式**：镜下负片转正片；**一行字亮起**（其余变暗、下划线、一个词飞出成读数卡）；钻进照片（镜框扩到画外，照片获得纵深）。
- **适合**：引用经典典籍（如《周易》《梦溪笔谈》古籍书影，需用公有领域扫描件）、历史档案、"这句话原文到底怎么说"。

## 已有视频引擎的升级路线（按收益排序）
1. **声音**：加拟音层（墨滴、笔刷、印章、小锣、磬）+ 每集两处真静音 + 两次 J/L-cut。`scripts/sfx.py` + `master.sh`，不改画面即可提升最多。
2. **留白与五墨**：把满屏金尘/光斑降到 30% 以下，画面 60% 以上留白；文字和图形只用五墨 + 金 + 一抹朱砂。
3. **原生转场**：场景切换从 whip-in/out 换成墨晕扩散（噪声径向遮罩 + 深色潮线），全片一套语法。
4. **按笔顺"画出来"**：八卦、汉字、五行图用 SVG 路径 stroke-dashoffset 按笔顺描出，配笔刷声，替代淡入。
5. **招牌镜头**：每集一个——手卷横摇、拉远揭示全图、或静默后的飞白。
6. **变速**：每集至少一次加速（列举段一拍一项）和一次喘息（4–8 s 的定格或长镜头）。
