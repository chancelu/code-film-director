# 导演方法（中文整理版）

整理自 lemo-opuscar `DIRECTOR.md` / `TECHNIQUE.md` 的思路，结合一个 13 集知识类系列的实际踩坑。章节号固定，其他文件会引用。

## 1. 接需求
- 默认：知识短片 60–180 s；竖版 1080×1920 或横版 1920×1080；中文字幕烧录并导出 `.srt`；响度 −14 LUFS。
- 超过 3 分钟：时间与 token 成倍增加，先告诉用户。
- 只问一次（主题里定不了的事、有无自有配音/音乐/素材、要不要先看分镜），之后不再问。

## 2. 先找标杆
写任何东西前，为"这个风格 × 这个题目"挑 1–2 个参考作品（动画片、片头、游戏、广告、纪录片），写下：
- **学什么**：构图、节奏、镜头语法、色彩逻辑、配乐结构。
- **不学什么**：角色、设计、旋律、具体镜头、logo、字体。

标杆对质量的提升大于下面任何一条规则。传统文化/哲学/科普常用标杆（只学语法）：
- 上海美影《山水情》（留白、墨晕、古琴节奏）
- 3Blue1Brown（一个概念一个视觉隐喻、公式按讲解顺序逐项出现）
- Kurzgesagt（扁平矢量、一镜一个比喻、尺度对比）
- The Pudding / 纽约时报图表叙事（图表本身就是故事）
- 《典籍里的中国》片头、故宫纪录片（器物特写、光从下往上）

## 3. 故事
- **一个主体、一个目标、一个转折**：一个概念（或一件器物、一个人）想要什么，发生了变化，结尾和开头不一样。
- **前 3 秒钩子**。不要慢悠悠的 logo/系列名。
- **呼应式结尾**：首尾同构、揭示全貌（拉远）、或让第二次做对。
- **一个原生招式**放在情绪高点（风格库里每种风格都列了）。
- **删多余**：缩略图尺寸能看懂的一个梗，胜过看不懂的三个。需要解释的段落就删。

知识类片的结构候选（每集写导演稿时至少列三种再选）：
| 结构 | 适合 |
|---|---|
| 一个问题一路追问 | 概念溯源（"为什么叫丙午年"） |
| 前后对比 / 误解→真相 | 破除常见误解（"立春不是春天开始"） |
| 倒计时 / 清单翻转 | 列举型内容，最后一项反转 |
| 一条线走到底（长卷/一笔画） | 历史、演化、时间轴 |
| 尺度揭示（推进或拉远） | 微观↔宏观、个人↔宇宙 |
| 两方对话 / 辩论 | 哲学观点对立（儒/道、决定论/自由意志） |
| 证明（板书逐步推导） | 逻辑、数学、因果链 |

## 4. 导演稿
在画任何东西前写 `TREATMENT.md`（模板 treatment-template.md）：
1. 三种结构候选 → 选定一种及理由。开场画面、结尾、配乐形状也从题目出发选；风格的第一反应通常是陈词滥调。
2. Logline（一句话）+ 起 → 转 → 合。
3. 标杆：学 / 不学。
4. 镜头表：每个镜头的景别（全/中/近/特写/插入）、角度、运动（推/拉/摇/移/升降/变焦）、时长，**以及为什么这样拍**。
5. 秒级节拍表。
6. 卡点表：BPM、小节网格、每段配器，每次切镜、关键动作、字幕落在哪一拍。
7. 音效表：每段的环境底、主要拟音、音乐状态。
8. 字幕与标题设计（字体是风格的一部分）。

## 5. 证明画风
无角色：出 3 张风格帧（一张是招牌镜头）。有角色：出设定表（转面、3–4 表情、2–3 关键姿势、色板）+ 2 张风格帧。必须用真实渲染代码出图，不用示意图，并对照 styles.md 自查。用户要分镜时，6–9 个关键镜头拼一张图，等确认。

## 6. 声音是半部片
- **每个可见动作都有声音**：落定、翻页、切、滴、点击、布料。材质不同声音不同（纸、木、金属、墨、玻璃）。
- **三层**：环境（风、雨、夜、寺院、书房）、拟音（跟动作）、音乐。对白和关键拟音出现时压低音乐（duck 6–8 dB）。
- **至少两处真静音**（或近乎静音），放在转折或情绪高点之前；静音后的第一个声音必须是全片最重要的声音之一。静音时整条总线归零（音乐、环境、混响尾巴），最多留一个声音（一滴水、一声磬）。
- **至少两次声音转场**：下一场的声音提前进（J-cut），或上一场的声音延续过剪切点（L-cut）。
- **避免泛滥的"钢琴+弦乐"**。按风格的声音调色板配器。

常见差距：只有 BGM，没有拟音和静音 → 最先补 `sfx.py` 事件音效和两处静音，收益最大。

## 7. 节奏：先有音乐网格
- 先写卡点表再做动画，画面锁网格，脚本检查每个卡点（目标 0 ms 误差）。
- **变速**：快慢交替，至少一次明显加速/减速，给观众一次喘息（长镜头或停住）。
- 一个动作、一个声音、一刀剪辑；但不要每拍都切，留时间看。
- **为观众排节奏，不为时钟**：
  - 字幕停留 ≥ 1.8 s，且 ≥ 念白时长 + 0.6 s。
  - 中文文字动画结束后再停 **字数 ÷ 4.5 + 1.5 秒**（按 BGM 排拍时可换算为：每条 ≥5 拍且 ≤2.8 字/拍，约 5 字/秒）。
  - 标题卡 ≥ 4 s。
  - 要快就减少每屏字数，不要在读完前切走。

## 8. 镜头：每个镜头都要有理由
- 至少 **4 种镜头运动** + 真正的景别变化。2D 也有镜头：推、拉、视差、焦点转移、画中画。
- **一个招牌镜头**：一镜到底、尺度揭示、或用媒介本身做的转场。
- **转场在媒介内部完成**（翻页、刻线生长、墨晕扩散），全片一套语法。避免默认淡入淡出和硬切。
- 关键时刻主体 ≥ 画面高度 1/3，调度清楚，剪影可读。
- 追随主体的效果（光圈、变焦、聚光）统一走一个"世界→屏幕"坐标函数，不手写屏幕坐标。

## 9. 表演（有角色/器物运动时）
- 每个有意义的动作都要 预备 → 动作 → 跟随。
- 姿势间用关键帧+缓动混合，不在 if 里切姿势（除非故意的一帧喜剧跳变）。
- 表情在最终尺寸下检查，尤其眉毛方向：担忧与愤怒只差一个翻转。

## 10. 最常见的失败
- 主体太小、太远或贴边。
- 太暗看不清，或同色叠同色（红底红字、金底金字）。
- 字幕压住主体。
- 梗/关键信息太快看不懂（实测最常见的返工原因）。
- 转场里出现空白帧（例如开头两帧白屏）。
- 定时效果在镜头移动后没跟住主体。

## 11. 交付前
- 质检循环：联系表（每 1–2 s 一帧，至少两轮）；关键动作 0.2 s 帧条；成片上测响度（ebur128）、黑帧（blackdetect）；带声音全速看一遍。`scripts/review.sh` 一键跑。
- **不要重复上一集**：和上一集比较 结构 / 开场 / 招牌镜头 / 镜头路径 / 配乐形状 / 结尾，六项至少四项不同。
- 响度约 −14 LUFS；无黑帧/白帧/NaN 帧；字幕同步且不压关键动作。
- 音效表里每一行都真的在混音里。
- 素材只用 CC0 / CC BY / OFL（字体用 Google Fonts，中文按用字子集化），在 CREDITS 里列出。陈述事实的科普片另附 `FACTS.md`：每条论断 + 出处。

## 12. 版权红线
参考只学语法。不复制角色、设计、旋律、镜头、logo、字体设计。现实作品、品牌、事件不进片，除非用户有权使用。
