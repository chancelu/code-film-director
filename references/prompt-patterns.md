# 提示词写法（提炼自 awesome-opus5-5-videos，703 条）

适用场景：用户要求"一句话出片"、写给其他 agent 的任务书，或者给自己立一份执行合同。

## 1. 高分提示词的共同骨架
1. **自主声明**：写明"Work autonomously end to end, do not ask questions"，免得做到一半来回确认。
2. **主体 + 真实数据**：不要写"讲讲五行"，要写"五行相生顺序、对应方位、颜色、五音的完整对照表"。数据要准确，能核对。
3. **一个场景一个强形式想法**："每个场景必须有一个只有动画才讲得清的视觉想法"，禁止只摆文字卡。
4. **rules 块**：技术约束写成清单，例如：
   - one `draw(t)` / `render(frame)`；no timers；no state between frames（画面完全由时间决定）
   - 所有动作对齐 BPM 网格，重拍落在关键动作上
   - 1080p30、时长 N 秒、字体内嵌
5. **deliverables 段**：逐项写出产出文件，包括 mp4、封面、源码、TREATMENT、联系表。
6. **验证循环**："先每拍出一帧拼成联系表，检查后再全量渲染；渲染后跑响度和黑帧检查，不合格就改了重来。"
7. **品味锚点**：写 1–2 部标杆作品，再写一条禁止项，比如"不要渐变霓虹、不要 emoji、不要 PPT 式飞入"。

## 2. 通用模板
```
做一支 {时长} 秒、{比例} 的 {主题} 短片，画面、音乐、音效、字幕全部用代码生成。
自主完成全流程，不要中途提问。

内容：{准确的知识点 / 数据，逐条列出}
开场：第 0 秒抛出问题"{问题}"，接金句"{金句}"，钩子"{钩子}"在第 {秒} 回收。
风格：{styles.md 某配方名}。参考 {标杆}，学它的 {点}，不学 {点}。
招牌镜头：{描述}。原生招式：{描述}。

rules:
- 画面是时间的纯函数 render(t)，不用定时器，帧之间不保存状态
- 按 {BPM} 的小节网格排事件；同一份时间轴驱动画面、音效、字幕
- 字幕每条 ≥ 字数÷4.5+1.5 秒；标题卡 ≥ 4 秒
- 至少 4 种镜头运动；转场在媒介内部完成；至少 2 处真静音、2 次 J/L-cut
- 响度 −14 LUFS，true peak ≤ −1 dBTP
- 禁止：{禁止项}

deliverables: final.mp4、cover_9x16.png、TREATMENT.md、contact_sheet.jpg、源码
verify: 先出每拍一帧的联系表并自查 → 全量渲染 → review.sh → 修到通过
```

## 3. 三类内容的一句话出片模板

**传统文化（水墨）**
> 做一支 90 秒、16:9 的"{主题}"传统文化科普片，用水墨风：宣纸底、五墨层次、大面积留白，图形按笔顺用 stroke 画出来，转场用墨晕扩散；声音用古琴 + 墨滴、笔刷、木鱼等拟音，两处真静音。第 0 秒抛问题"{问题}"。引用经典写《书名》。招牌镜头：{例：一滴墨落下晕开成太极}。

**哲学（一笔画）**
> 做一支 120 秒的哲学短片讲"{命题}"，一笔画风格：白底，全片一条连续不断的黑线，线条变形完成所有转场；配乐用单件钢琴，留大量静音。结构用"提问 → 反例 → 翻转"。招牌镜头：{例：线条画出的人走进自己画出的门}。

**科普（白板 / 数据叙事）**
> 做一支 90 秒科普片讲"{现象}"，白板手绘风（或数据叙事风）：每个数字都从真实数据生成图形，单位和来源写在画面角落；镜头跟着笔尖走，重要数字出现时停一拍并配一个音效。结构用"反直觉事实 → 拆解 → 回到生活"。

## 4. 常见扣分项
- 只给主题、没给数据，模型会编内容
- 没有 rules，会出现定时器、随机数，导致每次渲染结果不一样
- 没有验证循环，导致直接交付闪帧、黑场、爆音的版本
- 风格写成形容词堆砌（"高级、大气、有质感"）。要写材质、配色、运动方式这些具体参数
